5 itens iniciais
Primeiro passo: esta é a estrutura inicial da biblioteca. Os cartões são exemplos e pastas de organização; os materiais reais serão adicionados à medida que colocarmos seus arquivos nas pastas correspondentes.

Como adicionar materiais

Guia rápido
01 · Guardar

Coloque o arquivo na pasta certa

Use as pastas esbocos, estudos-biblicos, apostilas ou modelos dentro desta biblioteca.

02 · Cadastrar

Atualize o catálogo

Abra o arquivo catalogo.json e registre título, categoria, descrição e caminho relativo do material.

03 · Publicar

Publique a pasta

Envie o conteúdo para um repositório do GitHub e ative o GitHub Pages. O endereço público abrirá esta página e os arquivos vinculados.
